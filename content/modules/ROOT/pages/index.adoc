= LB8685: Accelerating Infrastructure Modernization with OpenShift Virtualization

*Red Hat One* へようこそ！

私たちのラボの多くは、テクノロジーとしてのOpenShift Virtualizationの実証や、環境における基本的な機能セット、運用のデモを行うことを目的としています。これは、このプラットフォームに初めて触れるお客様や、OpenShiftプラットフォームの基礎的な理解をお持ちのお客様の懸念を解消するためのものです。これらのお客様の多くは、仮想化のみを関心事とする従来のハイパーバイザーから移行してきており、他のテクノロジーやワークフローを統合して「近代化（モダン化）」するという概念自体、考えたこともないケースがほとんどです。

そこで本ラボでは、OpenShift Virtualizationをモダナイズされた視点から使用することを主目的としています。OpenShift Lightspeedのような新しいツールや統合機能の活用、および仮想マシンとコンテナを組み合わせた実際のワークフローを通じて、アプリケーションのライフサイクルにおいてこれら2つのテクノロジーをどのように共存・活用できるかをデモします。これには、高度なネットワーキング、ポリシー駆動型の運用、バージョン管理された構成（GitOps）といった概念が、仮想マシンおよびそれらに依存するアプリケーションに対するモダンなアプローチをどのように実現するかの実証も含まれています。

[[value-prop]]
== Value Prop（価値提案）

=== なぜコンテナと仮想化を一緒に使うのか？

* Red Hat OpenShift上でコンテナと仮想マシンを同時に実行することで、チームは独自のペースでモダナイズを進めることができます。既存のVMベースのワークロードを維持しながら、単一の一貫したプラットフォーム上で新しいクラウドネイティブ・アプリケーションを構築できます。

=== なぜ仮想化環境のデプロイにGitOpsを使うのか？

* GitOpsとArgo CDを使用して仮想化環境をコードとして管理（IaC）することにより、チームはガバナンスと一貫性を維持し、プロビジョニングを加速させながら、デプロイやDay 2運用を大幅に簡素化できます。

=== サービスメッシュはアプリケーションの機能にどう影響するか？

* サービスメッシュ（Service Mesh）であるIstioを使用することで、チームはOpenShift上のコンテナ型ワークロードとVM間でトラフィック管理、セキュリティ、可視性を一元的に制御できるようになり、統合されたハイブリッド・アプリケーション・プラットフォームが実現します。

=== ユーザーレベルの運用をセルフサービスへ拡張するには？

* KubernetesのRBAC（ロールベースアクセス制御）、テンプレート、および自動化を組み合わせることでセルフサービス化が可能になり、プラットフォームチームがガバナンスと制御を維持したまま、ユーザーはオンデマンドでVMやアプリケーションをプロビジョニングできるようになります。

=== OpenShift Virtualizationによるマルチクラウド運用のメリットは？

* 仮想化を含むOpenShiftの機能とメリットは、データセンター内のベアメタル環境だけでなく、クラウド上でも同様に利用できます。これにより、お客様は真のハイブリッドクラウド・インフラストラクチャを構築し、コンテナかVMかを問わず、すべてのワークロードを必要な場所で実行できるようになります。

[[lab-summary]]
== Lab Summary（ラボの概要）

このラボでは、3つのメインモジュールに加えて、将来的に拡張される予定の2つのインタラクティブなビデオモジュールを扱います。

*VM Foundations with OpenShift Lightspeed（OpenShift LightspeedによるVMの基礎）*:

* 参加者はOpenShift Virtualizationの基本をおさらいし、OpenShift Lightspeedがワークロードのトラブルシューティングやプロビジョニングの支援を通じて、いかに業務を効率化できるかを探ります。

*Service Mesh Integration with Virtual Machines（仮想マシンとサービスメッシュの統合）*:

* 参加者は、コンテナと仮想マシンの両方を利用するアプリケーションをデプロイし、高度なネットワークメトリクス、トラフィックシェーピング、および強化されたセキュリティのためのサービスメッシュを組み合わせることで、アプリケーション管理に対するモダンなアプローチを体験します。

*Declarative Management of VMs with GitOps Automation（GitOps自動化によるVMの宣言型管理）*:

* 参加者は、構成、アプリケーションのデプロイ、および管理にGitOpsを利用するアプリケーションをデプロイします。

*Self-service VM Provisioning with Developer Hub（Developer HubによるセルフサービスVMプロビジョニング）*:

* このインタラクティブなビデオモジュールでは、Developer Hubを使用して仮想マシンワークロードのプロビジョニングと管理を行ういくつかの機能について実演します。

*OpenShift Virtualization in the Cloud（クラウドにおけるOpenShift Virtualization）*:

* このインタラクティブなビデオモジュールでは、サポートされている複数のクラウドプロバイダーにおけるOpenShift Virtualizationのデプロイと管理について実演します。
